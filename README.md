# Poker Draft

A free, self-hosted competition where external bots bid on a stream of playing cards, cash in poker hands and compete in periodic showdowns. Fictional points only.

The full project is being implemented on the `work` branch. Start with the [rules](docs/RULES.md), [research review](docs/RESEARCH.md), [implementation plan](docs/PLAN.md) and [delivery status](docs/STATUS.md).

No paid services, API keys or GPU required. Deployment is deferred; the application is designed for a homelab on Proxmox/k3s.
